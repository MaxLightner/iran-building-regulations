# گزارش تحویل فاز صفر — ۲۰۲۶/۱۰/۲۹

این تحویل اسکلت محلی است؛ راه‌اندازی PostgreSQL در این محیط محقق نشده است. هیچ پروژه موجود، از جمله کمچه، تغییر نکرده است.

## خروجی‌های ساخته‌شده

- پروژه مستقل با frontend/، backend/، db/migrations/، scripts/، docs/ و sources/manifest.json و مخزن Git محلی روی main.
- README فارسی، راه‌انداز PowerShell، .gitignore و .env.example؛ PDF، فایل env، cache و logs خصوصی از Git کنار گذاشته می‌شوند. مجوز کد عمداً انتخاب نشده است.
- رابط فارسی RTL با انتخاب شهر، کاربری، اسکلت و مرحله، اسلایدر و ورودی اعشاری دقیق زیربنا، شمارنده مستقل طبقات و زیرزمین، ویرایش مشخصات و جست‌وجوی متنی.
- API نسخه‌دار health، sources، topics، search و project-preview و قرارداد OpenAPI 3.1؛ پاسخ صریح برای داده خالی؛ خطای 503 برای اتصال DB خراب.
- migration اولیه PostgreSQL شامل sources، documents، editions، sections، clauses، tags، applicability_conditions، clause_revisions، source_checks، references و topics. هیچ بند، جدول مقررات، عامل کلیدی یا شرط کاربرد ساختگی درج نشده است.
- بررسی دستی URLهای رسمی، کنترل فرمت PDF، SHA-256 و نگهداری نسخه با نام هش خارج Git؛ تغییر هش فقط رویداد بررسی است و نسخه معتبر یا دیتابیس را خودکار به‌روز نمی‌کند.
- مستندات تصمیم‌های فنی، API، مجوز و TODO دقیق استخراج، بازبینی انسانی و تطبیق نسخه‌ها. Pro/AI/صوت صرفاً در نقشه آینده آمده‌اند.

## منابع و اعتبار

فهرست جدید [مباحث دفتر مقررات ملی](https://inbr.ir/?page_id=5825) دارای ۲۴ مبحث است، اما [فهرست دانلود قدیمی](https://inbr.ir/?page_id=2032) ۲۳ مبحث را نشان می‌دهد. این اختلاف ثبت شده و از آن اعتبار یا تاریخ اجرای نسخه‌ها نتیجه‌گیری نشده است.

manifest شامل ۲۴ سند شماره‌ای مبحث و ۴ سند تکمیلی/اصلاحیه/ابلاغیه است: اصلاحیه مبحث ۷، اصلاحیه‌های ۱ و ۲ مبحث ۱۱، پیوست حفاظتی انتظامی مبحث ۴ و مصوبه مرتبط با مبحث ۹. در مجموع ۶۴ URL شامل ۳۵ لینک مستقیم PDF شناسایی و برای دریافت بررسی می‌شوند. ۹ لینک از PDFها پیوست‌های [ویرایش پنجم مبحث ۱۹](https://inbr.ir/?p=5798) هستند.

نسخه‌هایی که سال و شماره آنها روی صفحات رسمی خوانا بود (از جمله مبحث ۵، ۱۶، ۱۸، ۱۹، ۲۰ و ۲۱) با همان اطلاعات ثبت شده‌اند. برخی نسخه‌های تاریخی عمداً نگهداری شده‌اند و به‌عنوان نسخه جاری معرفی نشده‌اند. برای مباحث ۳، ۶، ۹، ۱۰، ۱۳، ۱۴ و ۲۴، صفحه رسمی شناسایی شد ولی نشانی مستقیم PDF جدید احراز نشد. در مباحث ۱۲، ۱۷ و ۲۲ فقط لینک قابل مشاهده در فهرست قدیمی ثبت شده است. عنوان کامل مباحث و تمام ویرایش‌ها/ابلاغیه‌ها هنوز به‌طور جامع احراز نشده‌اند.

متن بعضی PDFهای رسمی از ابزار وب قابل مشاهده بود؛ این دسترسی معادل دریافت باینری و محاسبه هش نیست. فیلد SHA-256 بدون باینری موفق null می‌ماند. نتیجه واقعی هر درخواست مستقیم، وضعیت HTTP، علت خطا و زمان بررسی در manifest و جدول گزارش sources-report.md ثبت می‌شود. هیچ منبع غیررسمی جای سند رسمی قرار نگرفته است.

تاریخ انتشار و اجرای مستندِ PDFها نامعلوم مانده است. تاریخ پست سایت، سال ویرایش، نام فایل و تاریخ پوشه URL به‌عنوان تاریخ اجرا استفاده نشده‌اند. هیچ سند یا بندی approved/current نشده است.

## آزمون‌ها و محدودیت‌ها

- ۸ تست داخلی موفق: صداقت پاسخ خالی، خطای قابل مشاهده DB، اعتبارسنجی پروژه، پارامتری و literal بودن جست‌وجو، نرمال‌سازی فارسی، مرز URL رسمی، هش و کنترل PDF، و نبود اعتبار تأییدشده جعلی.
- smoke واقعی HTTP موفق: سلامت، فهرست منابع، موضوع/جست‌وجوی خالی، preview پروژه، رد ورودی نامعتبر، نداشتن دسترسی عمومی به .env/manifest/README و دریافت OpenAPI.
- تست مرورگر Chrome موفق: تکمیل ویزارد، زیربنای اعشاری، شمارنده زیرزمین، مشاهده داده خالی، جست‌وجو و لینک رسمی؛ اندازه دسکتاپ، موبایل ۳۷۵ و حالت افقی، متن ۲۰۰٪، بدون سرریز افقی و خطای JavaScript. تصاویر نمونه در خروجی‌های کنار پروژه قرار دارند.
- بررسی نحوی JavaScript موفق. migration و import روی PostgreSQL واقعی اجرا نشده‌اند؛ PostgreSQL، Docker/psql و psycopg در محیط در دسترس نبودند. آزمون پایگاه داده در فاز بعد الزامی است.
- دمو محلی در زمان تحویل روی http://127.0.0.1:8766 فعال بود؛ نشانی عمومی و دائمی نیست. اجرای پیش‌فرض README روی 8765 است. درخواست باز کردن دمو در پنل برنامه به حالت queued رسید؛ نمایش خود پنل تأیید نشده است.

## GitHub و دسترسی

حساب متصل GitHub با login برابر MaxLightner تأیید شد، اما ابزار متصل عملیات create-repository ندارد. کنترل مرورگر پیش از ساخت مخزن متوقف شد چون URL جاری Windows را با اطمینان کافی تشخیص نمی‌داد. پس از تلاش مجدد، دسترسی API برقرار شد. مخزن خصوصی مستقل در https://github.com/MaxLightner/iran-building-regulations ایجاد شد؛ وضعیت بارگذاری کد با Git بررسی شود.

هیچ نرم‌افزار، وابستگی یا سرویس پولی نصب نشده؛ دسترسی امنیتی تازه‌ای ایجاد نشده است. انتخاب مجوز کد و روشن‌کردن مجوز بازنشر PDFها همچنان لازم است. دسترسی آزاد به لینک دانلود به معنی مجوز بازنشر عمومی تلقی نشده است.

## قدم بعدی

پس از رفع دسترسی منابع و GitHub و آماده‌شدن PostgreSQL، metadata را وارد کنید؛ فایل‌های رسمی را با شناسنامه/ابلاغ تأیید و سپس استخراج ساختاریافته بند، جدول و تبصره را آغاز کنید. فقط پس از بازبینی انسانی و ثبت منبع/صفحه/نسخه، موضوع‌ها و پاسخ‌های عملیاتی فعال شوند. [workflow دقیق](extraction-workflow.md) ترتیب کار را مشخص می‌کند.
