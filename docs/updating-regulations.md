# به‌روزرسانی یک مبحث

پس از جایگزینی یا دریافت نسخه جدید PDF یک مبحث، workflow دستی **Rebuild one regulation chapter** اجرا می‌شود.

ورودی فقط شماره مبحث ۱ تا ۲۴ است. خط تولید:
1. استخراج مجدد تمام صفحات همان PDF
2. کنترل هش و provenance منبع
3. بازسازی page index کل مجموعه
4. بازسازی Knowledge Index
5. بازسازی project relevance index
6. اجرای تست ۲۴ مبحث و benchmark جست‌وجو
7. commit خروجی فقط در صورت موفقیت همه آزمون‌ها

اگر PDF با هش ثبت‌شده در `sources/reference-mirror-report.json` تطبیق نداشته باشد، استخراج عمداً متوقف می‌شود. در آن حالت ابتدا باید منبع/نسخه PDF در گزارش منبع ثبت شود؛ سیستم نباید تغییر فایل را بی‌صدا بپذیرد.

پس از فعال‌شدن workflow انتشار، commit موفق این مرحله می‌تواند نسخه جدید سایت را نیز از pipeline انتشار عبور دهد.
