# وضعیت مجوز

مجوز کد و مالک حقوق آن از درخواست معلوم نیست؛ LICENSE انتخاب نشده است. انتخاب MIT/Apache یا هر مجوز دیگر نیاز به تصمیم مالک دارد.

صفحات دفتر مقررات ملی عبارت حفظ حقوق سایت دارند. دسترسی عمومی و دکمه دانلود مجوز روشن بازنشر در GitHub عمومی محسوب نشده است. در PDF تاریخی مبحث ۱۹ نیز عبارت حفظ حق چاپ مشاهده شد. بنابراین همه فایل‌های PDF در manifest وضعیت redistribution نامشخص دارند و از Git حذف شده‌اند. فقط metadata و نشانی رسمی قابل انتشار آماده است. این یادداشت ادعای تعیین وضعیت حقوقی تمام مقررات نیست.

فایل دریافتی فقط خارج مخزن و در فضای محلی خصوصی نگهداری شود؛ قبل از استفاده از cloud storage، نوع دسترسی و مجوز آن بررسی شود. .gitignore جای کنترل مجوز و بررسی فایل‌های staged را نمی‌گیرد.
