# فاز ۴ — موتور پروژه

## وضعیت
تکمیل شد.

## ورودی پروژه
- شهر
- کاربری
- نوع سازه
- زیربنای کل
- تعداد طبقات روی زمین
- تعداد زیرزمین
- مرحله پروژه

## رفتار موتور
موتور روی ۱۵۰۱۷ رکورد دانش ساختاریافته، سیگنال‌های پروژه را استخراج و برای رتبه‌بندی استفاده می‌کند:
- ۱۱۱۶ رکورد با اشاره مستقیم به کاربری
- ۹۵۸ رکورد با اشاره مستقیم به نوع سازه
- ۱۶۱ رکورد مرتبط با زیرزمین
- ۸۳ شرط عددی کاندید برای مساحت/طبقات/زیرزمین
- مرحله پروژه از متن و مبحث استنتاج می‌شود

نتایج حذف قطعی نمی‌شوند. مشخصات پروژه فقط ترتیب و توضیح «چرا این نتیجه مرتبط است» را تغییر می‌دهد.

## توضیح نتیجه
برای هر رکورد در صورت وجود شواهد، رابط می‌تواند توضیح دهد:
- کاربری پروژه در متن ضابطه دیده شده
- نوع سازه با متن ضابطه همخوان است
- مرحله پروژه مرتبط است
- ضابطه به زیرزمین مربوط است
- شرط عددی استخراج‌شده با پروژه همخوان است

سه سطح نمایش:
- مرتبط‌تر با پروژه
- مرتبط با پروژه
- ارتباط عمومی / نیازمند بررسی

## شهر
فعلاً شهر به‌طور عمدی فیلترکننده نیست، چون مجموعه فعلی مقررات ملی ساختمان است.
اگر بعداً داده‌های اقلیمی، پهنه‌بندی، بار برف/باد، زلزله یا مقررات محلی وارد شوند، شهر می‌تواند به موتور شرطی اضافه شود.

## سیاست ایمنی داده
سیگنال‌های پروژه حکم قانونی تولید نمی‌کنند و رکوردی را به‌خاطر تشخیص نامطمئن حذف نمی‌کنند.
PDF و صفحه منبع برای کنترل نهایی حفظ شده‌اند.
