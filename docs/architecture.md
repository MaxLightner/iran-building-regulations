# تصمیم‌های فاز صفر

- محصول و مخزن مستقل؛ هیچ فایل یا تنظیم کمچه تغییر نمی‌کند. کمچه در آینده مصرف‌کننده `/api/v1` است.
- PostgreSQL 16+ مرجع عملیاتی است. PDF و هش برای هویت نسخه و مقایسه آتی است؛ manifest مرجع حکم مهندسی نیست.
- سرور توسعه Python 3.11+ با کتابخانه استاندارد و WSGI برای اجرای بدون نصب انتخاب شده است؛ FastAPI الزام این اسکلت نیست. PostgreSQL فقط به درایور اختیاری psycopg نیاز دارد. این درایور اینجا نصب نشده است.
- frontend با HTML/CSS/JavaScript ساده، هم‌مبدأ با API، بدون build، بسته، CDN، AI، صوت یا سرویس پولی است.
- حالت بدون DATABASE_URL صرفاً فهرست شناسایی manifest و موضوعات/جست‌وجوی خالی دارد. خرابی اتصال تنظیم‌شده خطای 503 است؛ پنهان نمی‌شود.
- هیچ موتور استنتاج کاربردپذیری ساخته نشده؛ مشخصات پروژه فقط اعتبارسنجی و بازتاب داده می‌شوند و ذخیره نمی‌شوند.
- پاسخ بند فقط با تأیید سند، نسخه و بند، وضعیت نسخه جاری، هش و نشانی PDF و صفحه/بند ممکن است. هیچ نسخه‌ای در فاز صفر جاری یا تأییدشده علامت نمی‌خورد.
- تاریخ انتشار، تاریخ بروزرسانی صفحه، تاریخ چاپ، تاریخ فایل سرور و تاریخ اجرای مقررات مستقل‌اند. مقادیر نامعلوم null هستند؛ متن تقویم اصلی و مدرک اجرا نگهداری می‌شود.
- جست‌وجو literal substring روی متن نرمال‌شده است؛ پارامتری، محدود به ۵۰ نتیجه، با escape برای % و _. نرمال‌سازی ی/ک و فاصله برای فاز استخراج استفاده می‌شود؛ متن اصلی دست‌نخورده باقی می‌ماند.
- editionهای جدید، بندها، جدول‌ها و تبصره‌ها جدا نگهداری می‌شوند؛ revision و reference ارجاع‌های شکسته، تغییر شماره، تجزیه و ادغام را پوشش می‌دهند.
- سرور WSGI برای توسعه است. احراز هویت، کنترل نرخ، پشتیبان‌گیری، نقش‌های بازبین، استقرار production و سخت‌سازی API فاز بعد هستند؛ فعلاً فقط localhost.
- مجوز کد انتخاب نشده است؛ نبود LICENSE نباید مجوز آزاد تلقی شود. قبل از انتشار عمومی مالک و مجوز را مشخص کنید. اسناد مقررات مجوز جدا دارند.

## طرح رابط حداقلی
پس‌زمینه آبی بسیار روشن #F3F7FA، متن سرمه‌ای #162D43، متن ثانویه #4B6172، اقدام سبزآبی #15636A و مرز #C4D1DB. تایپوگرافی محلی Tahoma/Segoe UI برای متن فارسی بدون بارگیری فونت. معرفی کوتاه، وضعیت داده در کنار آن، ویزارد دو مرحله‌ای و فهرست منابع بازشونده. از الگوی بازاریابی پرجزئیات صرف‌نظر شده تا وضعیت اعتبار و مسیر کار مشخص باشد. برچسب ورودی، فوکوس قابل مشاهده، فرم راست‌به‌چپ و چیدمان تک‌ستونه موبایل رعایت شده‌اند.
