# لایه دانش مقررات — معیار واقعی فاز ۳

این لایه بین OCR و رابط کاربر قرار می‌گیرد و مبنای جست‌وجوی نهایی است.

## خط تولید
PDF → متن صفحه → تفکیک رکوردهای بندمانند → موضوعات → فاکتورهای عددی → شروط/قیود → ارجاعات → روابط موضوعی → ایندکس جست‌وجوی دانش

## وضعیت فعلی
روی ۹ سند موجود اجرا شده است:
- مباحث ۳، ۴، ۵، ۶، ۷، ۹، ۱۰ و ۱۵
- پیوست حفاظتی انتظامی مبحث ۴

خروجی فعلی:
- ۷۶۸۴ رکورد ساختاریافته
- ۱۵۱۱ فاکتور عددی با متن زمینه
- ۷۶۰۸ جمله/قید شرطی
- ۱۴ موضوع اصلی و روابط صریح بین آن‌ها

این اعداد به معنی «۷۶۸۴ بند قانونی تأییدشده» نیستند؛ واحدهای ساختاریافته‌ای هستند که مستقیماً از متن PDFها ساخته شده‌اند.

## رفتار محصول
جست‌وجوی پیش‌فرض رابط باید روی `frontend/data/knowledge/` انجام شود.
هر نتیجه می‌تواند شامل این موارد باشد:
- عنوان/شماره بند تشخیص‌داده‌شده
- خلاصه استخراجی
- متن کامل همان رکورد
- موضوعات اصلی
- موضوعات مرتبط
- اعداد و واحدهای مهم با متن اطراف
- شروط و قیود
- ارجاعات داخلی یا بین مباحث
- مبحث و شماره صفحه PDF
- لینک PDF فقط به عنوان مدرک منبع

## معیار پایان فاز ۳
فاز ۳ زمانی تمام است که:
1. تمام ۲۴ مبحث و پیوست‌های موردنظر از همین pipeline عبور کرده باشند.
2. همه خروجی‌ها در ontology و knowledge index قرار گرفته باشند.
3. تست‌های جست‌وجوی واقعی برای موضوعات مهم نتیجه مرتبط برگردانند.
4. کاربر برای پیدا کردن ضابطه عادی مجبور به بازکردن PDF نباشد.

اعتبار رسمی آخرین ویرایش و تاریخ لازم‌الاجرا شدن می‌تواند جداگانه در فاز اعتبارسنجی/نسخه‌ها تکمیل شود، اما متن و عدد استخراج‌شده باید به صفحه منبع قابل ردیابی باشد.
