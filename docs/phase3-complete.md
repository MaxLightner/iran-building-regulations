# فاز ۳ — تکمیل شد

## نتیجه نهایی
تمام ۲۴ مبحث موجود در آرشیو پروژه از pipeline کامل عبور کرده‌اند:

PDF → متن صفحه → رکورد ساختاریافته → موضوع → عدد/واحد → شرط/قید → ارجاع → روابط موضوعی → Knowledge Index

پیوست حفاظتی–انتظامی مبحث ۴ نیز به‌عنوان سند بیست‌وپنجم در ایندکس وجود دارد.

## آمار
- ۲۴ مبحث اصلی
- ۲۵ سند با احتساب پیوست مبحث ۴
- ۴۹۰۴ صفحه PDF ایندکس‌شده
- ۴۷۹۵ صفحه دارای متن قابل جست‌وجو
- ۱۵۰۱۷ رکورد دانش ساختاریافته
- ۲۶۶۲ فاکتور عددی با واحد/زمینه
- ۱۵۶۲۵ جمله شرطی/قیدی
- ontology مشترک و روابط موضوعی بین مباحث

## رفتار محصول
جست‌وجوی اصلی باید از frontend/data/knowledge/ استفاده کند.
بازکردن PDF برای پیدا کردن ضابطه لازم نیست؛ PDF صرفاً منبع و مدرک هر نتیجه است.
حالت draft/page-search فقط برای اشکال‌زدایی و مشاهده متن خام استخراجی باقی می‌ماند.

## کنترل کیفیت فاز ۳
تست نهایی الزام می‌کند:
1. هر ۲۴ مبحث در page index و knowledge index وجود داشته باشد.
2. تمام صفحات هر PDF بدون gap ثبت شده باشند.
3. هر مبحث حداقل رکورد دانش قابل جست‌وجو داشته باشد.
4. provenance هر رکورد به مبحث، PDF و صفحه قابل ردیابی باشد.
5. جست‌وجوی مرورگر روی موضوعات و رکوردهای ساختاریافته پاسخ برگرداند.

## محدودیت باقی‌مانده
این مرحله اعتبار رسمی آخرین ویرایش یا لازم‌الاجرا بودن مقررات را اثبات نمی‌کند.
OCR، تشخیص ساختار و extraction ممکن است خطا داشته باشند؛ منبع PDF برای بررسی حفظ شده است.

مرحله بعدی محصول، موتور project applicability است:
مشخصات ساختمان → تشخیص و اولویت‌بندی ضوابط مرتبط از همین Knowledge Index.
