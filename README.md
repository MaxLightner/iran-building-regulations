# مقررات ملی ساختمان ایران — پایه منابع

این مخزن فعلاً فقط **پایهٔ منابع** پروژه است.

## وضعیت فعلی

هیچ موتور جست‌وجو، دیتابیس ضابطه، Rule DB، شاخص موضوعی، رتبه‌بندی پروژه یا دادهٔ استخراج‌شده‌ای در این نسخه وجود ندارد.

آنچه نگه داشته شده:

- فایل‌های PDF خام موجود در `sources/pdfs/`
- متادیتا و گزارش منشأ فایل‌ها در `sources/`
- ابزار بررسی و دریافت از منابع رسمی
- یک صفحهٔ عمومی خنثی که هیچ ضابطه یا پاسخ مهندسی نمایش نمی‌دهد

PDFهای موجود صرفاً **آرشیو خام و تأییدنشده** هستند. قبل از هر پردازش بعدی باید برای هر فایل جداگانه بررسی شود:

1. نسخه و منشأ سند
2. وجود text layer واقعی و سالم
3. قابلیت انتخاب/استخراج متن فارسی
4. پوشش صفحات
5. عدم نیاز به حدس یا بازسازی از تصویر

تا وقتی این کنترل منبع تمام نشده، هیچ دادهٔ مهندسی از این فایل‌ها تولید نمی‌شود.
