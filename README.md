# مقررات ملی ساختمان ایران — مرحلهٔ جمع‌آوری منبع

در این مخزن فعلاً **هیچ PDF و هیچ دادهٔ استخراجی** نگهداری نمی‌شود.

هدف مرحلهٔ فعلی فقط این است:
- پیدا کردن نسخه‌های معتبر و قابل استناد مباحث
- بررسی اینکه PDF واقعاً text layer سالم دارد
- ثبت منشأ و نسخه
- شروع پردازش فقط پس از تأیید منبع

تا آن زمان هیچ Rule DB، OCR، جست‌وجوی مهندسی یا دیتابیس ضابطه ساخته نمی‌شود.
