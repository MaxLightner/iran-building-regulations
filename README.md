# پایگاه مقررات ملی ساختمان — بازنشانی داده‌ها

پایگاه داده و تمام خروجی‌های استخراج، تصاویر تولیدشده، نمایه‌های جست‌وجو و نمونه رابط قبلی در ۳۰ اکتبر ۲۰۲۶ از شاخه اصلی حذف شدند.

## منابع محفوظ

- `sources/manifest.json`: فهرست منابع و صفحات کشف‌شده
- `sources/chapters.json`: موضوعات ۲۴ مبحث و نشانی فایل‌ها و صفحات مرتبط
- `sources/text-source-inventory.json`: فهرست نشانی‌های بررسی‌شده برای متن منابع
- `sources/submitted-document-audit.json`: مشخصات فایل‌های ارائه‌شده، شامل نام، ویرایش و اثرانگشت فایل
- `sources/README.md`: توضیح محل نگهداری منابع

**توجه:** فایل PDF اصلی در این مخزن GitHub وجود ندارد؛ اینجا فقط نشانی‌ها و مشخصات آن‌ها نگهداری می‌شود. فایل‌های ارسالی کاربر خارج از مخزن‌اند.

## وضعیت

- رکورد مقررات: ۰
- ایندکس جست‌وجو: ندارد
- تصاویر استخراج‌شده: ندارد
- فرایند استخراج خودکار: متوقف
- سایت: صفحه وضعیت بازسازی، بدون نمایش داده قدیمی

ساختار جدید و ضوابط ورود اطلاعات در مرحله بعد تعریف خواهند شد. تاریخچه Git قابل بازیابی است، اما داده‌های قدیمی در نسخه جاری وجود ندارند.
